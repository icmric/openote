# Archive

Work that has shipped. These describe what was decided and why, at the time —
**not the current state of the app.** Where one of these disagrees with the
code, the code is right.

They are kept because every one of them has since answered a question the code
alone could not: why a thing is shaped the way it is, what the measurement was,
and which alternative was tried and dropped. Anything still *open* was moved out
to [backlog.md](../backlog.md) before these were archived.
